# AI-Powered_Career_Intelligence_Platform
An AI-powered career guidance platform developed as part of the Infosys Springboard Virtual Internship Project. The platform aims to help students explore suitable career paths, identify skill gaps, receive personalized career recommendations, and discover relevant learning resources based on their skills, interests, and goals.

## 📌 About the Project

Choosing the right career path can be challenging for students and job seekers. The AI-Powered Career Intelligence Platform aims to simplify career planning by helping users explore suitable career opportunities, understand the skills required for specific roles, and identify learning opportunities for professional growth.

The platform combines a responsive web interface with a Python backend to support career guidance and AI-based career intelligence.

## 🎯 Objectives

- Provide personalized career guidance based on users' interests and skills.
- Help users identify skill gaps for their desired career paths.
- Support career planning and professional development.
- Recommend relevant learning resources.
- Make career exploration more accessible and user-friendly.

## ✨ Key Features

- **Career Recommendations:** Helps users explore career options aligned with their skills and interests.
- **Skill-Gap Analysis:** Identifies skills that may need improvement for a target career.
- **Career Pathway Guidance:** Supports users in understanding potential career progression.
- **Learning Resource Suggestions:** Helps users identify relevant learning opportunities.
- **Responsive User Interface:** Provides a user-friendly interface built with Bootstrap.
- **Python Backend:** Handles server-side processing and supports the platform's core functionality.

*Note: The features listed above should reflect the functionality implemented in the project.*

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

- Python 3.x
- Git
- A modern web browser
- A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd AI-Powered-Career-Intelligence-Platform
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment.

**macOS/Linux:**

```bash
source venv/bin/activate
```

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

If your project contains a `requirements.txt` file, run:

```bash
pip install -r backend/requirements.txt
```

### 5. Run the Backend

If your Python entry-point file is `backend/app.py`, run:

```bash
python backend/app.py
```

Use the command appropriate to your backend framework and configuration.

### 6. Launch the Frontend

Open the frontend through your configured local web server or backend. If the frontend is standalone, open `index.html` in your browser.
